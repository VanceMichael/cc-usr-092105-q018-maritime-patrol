# 领域约定

## 核心对象

- 船舶档案
- 船员档案
- 货物记录
- 航道与航标
- 水位气象
- 视频证据
- 感知事件
- 电子预警
- 证据快照
- 现场任务
- 任务认领记录
- 复核结论

## 已知规则

### 核验与闭环

- 线上预警必须等待现场或远程核验
- 预警处置按叫应、接收、现场检查、处置复核逐步推进，状态只能由现场反馈驱动
- 判定为误报或现场无法到达时，必须记录原因后任务才能关闭或退回

### 证据溯源与不可变性

- 电子预警必须携带来源系统、发现时间、船舶标识和事件内容四要素
- 传感修正不能覆盖当时证据
- 船名或船舶标识变更、传感数据修正、预警级别升级均须留存证据快照，原值不得被覆盖
- 多源信息按事件发生时间归序，乱序到达只能追加记录，不得回改已确认的状态与证据

### 任务唯一性与离线补传

- 同一条电子预警只能对应一项现场检查任务，返航补传不得重复建单
- 多人同时抢单时只确认一个认领人，其余认领记录保留但不生效

### 统一视图与权限

- 四类来源（智慧海事、CCTV、VTS、智慧运河平台）的船舶、船员、货物、航道、航标、水位气象及视频证据汇入值班中心统一监管视图
- 指挥端只呈现尚未响应、正在核查、已经消除三种统一状态，以核查系统为唯一事实来源
- 执法材料按案件权限查看
- 桥区、锚地材料仅向具备对应职责的岗位开放，越权访问不可见且留痕

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
