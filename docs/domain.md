# 领域约定

## 核心对象

- 船舶档案
- 感知事件
- 电子预警
- 现场任务
- 复核结论
- 统一视图
- 证据快照

## 电子预警溯源

每条电子预警必须说明四件事：哪套系统（智慧海事、CCTV、VTS 或智慧运河平台）、哪个时间点、用什么船舶标识、发现了什么。巡查员在平板上看到桥区异常时，首先核对这四项再出发。

## 预警处置阶段

预警按叫应、接收、现场检查、处置复核逐步推进。误报或无法到达同样留下原因，不留空白。同一预警的返航补传沿用原标识，不生成第二项现场任务。

## 指挥端状态

指挥端只呈现三种真实状态：尚未响应、正在核查、已经消除。状态以统一视图为准，各系统不各自另算。

## 已知规则

- 线上预警必须等待现场或远程核验
- 传感修正不能覆盖当时证据
- 执法材料按案件权限查看
- 电子预警必须带来源系统、发现时间和所用船舶标识
- 同一预警的返航补传不得生成第二项现场任务
- 误报或无法到达必须留下原因
- 船名与标识变化、多源乱序、多人抢单、船上断网、传感修正和预警升级都要保持当时证据
- 桥区与锚地材料按职责开放
- 指挥端状态以统一视图为准，各系统不各自另算

样例中的名称和编号仅用于说明字段关系，不能对应到现实中的个人、企业或业务记录。
